# SovereignStack Maturity Model

This document outlines the maturity stages of SovereignStack protocol specifications and reference integrations. 

To prevent exaggerating maturity in a high-compliance enterprise space, integrations and profiles are rigorously categorized by the following levels.

## Implemented
Code exists and automated tests pass in a local CI environment. 

## Fixture Validated
Protocol behavior has been demonstrated using deterministic reference fixtures (e.g., simulating integration events via mock payloads).

## Integration Validated
The adapter has been executed against a live external platform. Real external calls are successfully governing infrastructure and producing verifiable evidence.

## Independently Conformant
An external, third-party implementation of the protocol has passed the complete conformance suite.

## Certified
An independent certification process has formally validated the implementation or profile against an industry framework (e.g., OASA, SOC 2, HIPAA).

## Vendor Endorsed
The platform vendor (e.g., HPE, VMware) has explicitly reviewed and formally endorsed the integration as a supported governance path.
