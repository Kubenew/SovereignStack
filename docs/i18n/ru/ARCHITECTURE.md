# Архитектура SovereignStack

**Редакция:** 1.0 — Май 2026  
**Статус:** Живой документ

---

## 1. Обзор системы

SovereignStack — это многоуровневая суверенная платформа ИИ-инфраструктуры. Каждый уровень имеет четко определенные границы, API и контракты безопасности. Данные строго передаются вверх через аутентифицированные шлюзы, контролируемые политиками.

## 2. Основные подсистемы

### 2.1 Суверенная среда выполнения
Уровень выполнения ИИ. Отвечает за загрузку моделей, инференс, планирование и изоляцию ресурсов.

### 2.2 Уровень памяти и координации
Постоянное, зашифрованное, распределенное хранилище для векторов, KV-кэшей и синхронизации состояния.

### 2.3 Уровень идентификации и безопасности
Идентификация с нулевым доверием для узлов, рабочих нагрузок и пользователей.

### 2.4 Уровень федерации и mesh-сети
Межузловое взаимодействие, обнаружение и синхронизация для многопрофильных развертываний.

## 3. Профили развертывания

| Профиль | Цель | Особенность |
|---------|------|------------|
| Edge | ARM-устройства, IoT | Инференс на CPU, локально, офлайн |
| Air-Gapped | Изолированные сети | GPU + CPU, AES-256 + TPM, без WAN |
| ЦОД | Кластеры GPU | Мульти-GPU vLLM, распределенная БД |
| Персональный | Ноутбук, домашняя лаборатория | CPU/GPU, локальная ФС, VPN по выбору |
