# SovereignStack

> **Sovereign Intelligence Network** — 面向智能的分布式操作系统。

SovereignStack 是一个协议栈和运行时，将智能本身视为一种网络资源。它之于自主智能，就如同 TCP/IP 之于数据网络。

主权智能不应依赖于单一语言、司法管辖区、云提供商或实现。

## 基本原则

每个 SovereignStack 对象都应具备：

1. **可识别** — 拥有唯一 URI
2. **可寻址** — 可通过网络解析
3. **可发现** — 可通过语义搜索找到
4. **可验证** — 带有加密签名和溯源链
5. **可移植** — 可在节点和司法管辖区之间移动
6. **可联邦** — 可跨越主权边界共享
7. **可审计** — 拥有完整的历史记录和推理路径

## RFC 概览

42 个 RFC（0001–0053）· 34 个 URI 方案 · 18 个协议

## 快速开始

```bash
git clone https://github.com/Kubenew/SovereignStack.git
cd SovereignStack
cargo build --workspace
cargo test --workspace
```
