# SovereignStack 架构

**修订版本：** 1.0 — 2026年5月  
**状态：** 持续更新文档

---

## 1. 系统概述

SovereignStack 是一个分层的主权 AI 基础设施平台。每一层都有明确定义的边界、API 和安全契约。数据通过经过身份验证和策略控制的网关严格向上流动。

## 2. 核心子系统

### 2.1 Sovereign 运行时
AI 执行层。负责模型加载、推理、调度和资源隔离。

### 2.2 内存与协调层
用于向量、KV 缓存和状态同步的持久加密分布式存储。

### 2.3 身份与安全层
为节点、工作负载和用户提供零信任身份。

### 2.4 联邦与网格层
用于多节点部署的节点间通信、发现和同步。

## 3. 部署配置

| 配置 | 目标环境 | 特点 |
|------|---------|------|
| 边缘 | ARM 设备、物联网 | CPU 推理、本地、离线 |
| 气隙 | 隔离网络 | GPU + CPU、AES-256 + TPM、无 WAN |
| 数据中心 | GPU 集群 | 多 GPU vLLM、分布式数据库 |
| 个人 | 笔记本电脑、家庭实验室 | CPU/GPU、本地文件系统、可选 VPN |
