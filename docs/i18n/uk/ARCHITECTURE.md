# Архітектура SovereignStack

**Редакція:** 1.0 — Травень 2026  
**Статус:** Живий документ

---

## 1. Огляд системи

SovereignStack — це багаторівнева суверенна платформа інфраструктури ШІ. Кожен рівень має чітко визначені межі, API та контракти безпеки. Дані строго передаються вгору через автентифіковані шлюзи, що контролюються політиками.

## 2. Основні підсистеми

### 2.1 Суверенне середовище виконання
Рівень виконання ШІ. Відповідає за завантаження моделей, інференс, планування та ізоляцію ресурсів.

### 2.2 Рівень пам'яті та координації
Постійне, зашифроване, розподілене сховище для векторів, KV-кешів та синхронізації стану.

### 2.3 Рівень ідентифікації та безпеки
Ідентифікація з нульовою довірою для вузлів, робочих навантажень та користувачів.

### 2.4 Рівень федерації та mesh-мережі
Міжвузлова комунікація, виявлення та синхронізація для багатовузлових розгортань.

## 3. Профілі розгортання

| Профіль | Ціль | Особливість |
|---------|------|------------|
| Edge | ARM-пристрої, IoT | Інференс на CPU, локально, офлайн |
| Air-Gapped | Ізольовані мережі | GPU + CPU, AES-256 + TPM, без WAN |
| ЦОД | Кластери GPU | Мульти-GPU vLLM, розподілена БД |
| Персональний | Ноутбук, домашня лабораторія | CPU/GPU, локальна ФС, VPN за вибором |
