## Translation Policy

1. **English is canonical.** All authoritative decisions, RFCs, and governance are resolved in English.
2. **Translations are maintained copies.** They reflect the canonical English documents at a point in time. When discrepancies arise, the English version prevails.
3. **Community contributions welcomed.** To add or update a translation, submit a PR against `docs/i18n/<lang>/`.
4. **Accuracy over speed.** Translations should be reviewed by at least one additional native speaker before merging.

## Adding a New Language

1. Create `docs/i18n/<lang>/` directory
2. Translate `README.md`, `CONSTITUTION.md`, and `ARCHITECTURE.md`
3. Add an entry to this index
4. Open a pull request
