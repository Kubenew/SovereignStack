# SovereignStack

> **Sovereign Intelligence Network** — 지능을 위한 분산 운영체제.

SovereignStack은 지능 자체를 네트워크 리소스로 취급하는 프로토콜 스택이자 런타임입니다. 이는 자율 지능에 있어 TCP/IP가 데이터 네트워킹에 가지는 역할과 같습니다.

주권적 지능은 단일 언어, 관할권, 클라우드 제공업체 또는 구현에 의존해서는 안 됩니다.

## 기본 원칙

모든 SovereignStack 객체는 다음을 갖춥니다:

1. **식별 가능** — 고유 URI 보유
2. **주소 지정 가능** — 네트워크를 통해 확인 가능
3. **발견 가능** — 의미론적 검색으로 탐색 가능
4. **검증 가능** — 암호학적 서명 및 출처 추적
5. **이식 가능** — 노드와 관할권 간 이동 가능
6. **연합 가능** — 주권 경계를 넘어 공유 가능
7. **감사 가능** — 전체 기록 및 추론 경로

## RFC 개요

42개의 RFC(0001–0053) · 34개의 URI 스키마 · 18개의 프로토콜

## 빠른 시작

```bash
git clone https://github.com/Kubenew/SovereignStack.git
cd SovereignStack
cargo build --workspace
cargo test --workspace
```
