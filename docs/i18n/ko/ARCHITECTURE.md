# SovereignStack 아키텍처

**개정:** 1.0 — 2026년 5월  
**상태:** 살아있는 문서

---

## 1. 시스템 개요

SovereignStack은 계층화된 주권 AI 인프라 플랫폼입니다. 각 계층은 명확하게 정의된 경계, API 및 보안 계약을 가집니다. 데이터는 인증되고 정책이 적용된 게이트웨이를 통해 엄격하게 위쪽으로 흐릅니다.

## 2. 핵심 하위 시스템

### 2.1 Sovereign 런타임
AI 실행 계층. 모델 로딩, 추론, 스케줄링 및 리소스 격리를 담당합니다.

### 2.2 메모리 및 조정 계층
벡터, KV 캐시 및 상태 동기화를 위한 영구적이고 암호화된 분산 스토리지.

### 2.3 신원 및 보안 계층
노드, 워크로드 및 사용자를 위한 제로 트러스트 신원.

### 2.4 연합 및 메시 계층
다중 노드 배포를 위한 노드 간 통신, 검색 및 동기화.

## 3. 배포 프로필

| 프로필 | 대상 | 특징 |
|--------|------|------|
| 엣지 | ARM 기기, IoT | CPU 추론, 로컬, 오프라인 |
| 에어갭 | 격리된 네트워크 | GPU + CPU, AES-256 + TPM, WAN 없음 |
| 데이터센터 | GPU 클러스터 | 멀티 GPU vLLM, 분산 DB |
| 개인 | 노트북, 홈랩 | CPU/GPU, 로컬 FS, 선택적 VPN |
