# SovereignStack v0.5 Verification Gate

This document is the externally reproducible procedure for verifying the **v0.5 Core Contract** — the minimum verifiable protocol for sovereign AI nodes:

```
Identity → Capability → Policy → Action → Provenance → Evidence
```

Any party can clone, build, and run the gate below and get an unambiguous pass/fail result.

## Prerequisites

- **Rust** stable toolchain (`cargo`, `rustc`)
- **Python** 3.12
- A bash shell (Linux, macOS, WSL, or Git Bash on Windows)

## The 7 Core Test Vectors

The Core Contract (profile `core-0.1`) is verified against 7 deterministic vectors, each mapped to a control ID and a machine-readable fixture in `conformance/vectors/`:

| Control | Vector | Description |
|---------|--------|-------------|
| `IDENT-001` | `identity-creation` | Ed25519 identity generation and verification |
| `OBJ-001` | `object-signing` | Cryptographic object signing and hash verification |
| `CAP-001` | `capability-grant` | Capability registration, grant, and revocation |
| `POL-001` | `policy-evaluation` | Policy rule matching and enforcement |
| `EVT-001` | `event-integrity` | Event publish/subscribe with integrity |
| `PROV-001` | `provenance-chain` | Hash-linked provenance chain creation and tamper detection |
| `EVID-001` | `evidence-generation` | Evidence package generation with conformance profile binding |

## One-Command Verification

```bash
git clone https://github.com/Kubenew/SovereignStack.git
cd SovereignStack

bash verify.sh
```

`verify.sh` runs the full gate and exits `0` only if every stage passes:

1. `cargo build --release`
2. `cargo test --workspace`
3. Python dependency setup
4. Reference node startup (`./target/release/ss-node --port 8546`)
5. Core Contract conformance harness (`tools/ss-conformance.py --profile core-0.1`) — **7 vectors must pass**
6. Security & conformance pytest suite, including the Morpheus integration tests (`pytest tests/ integrations/morpheus/tests`)
7. Claims matrix validation

A final banner (`STATUS: CORE CONTRACT VERIFIED`) indicates success.

## Step-by-Step Verification

If you prefer to run the stages individually:

```bash
# 1. Build the reference node
cargo build --release

# 2. Run the Rust workspace tests
cargo test --workspace

# 3. Install Python dependencies
pip install pytest pytest-asyncio requests pyyaml cryptography

# 4. Start the reference node in the background
./target/release/ss-node --port 8546 &

# 5. Run the Core Contract conformance harness (7 vectors)
python tools/ss-conformance.py --endpoint http://localhost:8546 --profile core-0.1

# 6. Run the security, conformance & integration pytest suite
pytest tests/ integrations/morpheus/tests -v --tb=short

# 7. Validate the claims matrix
python tools/validate_claims.py
```

## Interpreting Results

- **Conformance harness**: prints `Conformance Summary: 7/7 PASS` and exits `0` when all vectors pass; otherwise exits `1`.
- **verify.sh**: exits non-zero and prints the failing stage if any stage fails; the reference node is torn down on both success and failure.
- **CI**: the `.github/workflows/ci.yml` `python-core` job runs `bash verify.sh` on every push/PR to `main` and **must pass** before merge.
