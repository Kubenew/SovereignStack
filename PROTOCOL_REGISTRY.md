## Protocol Lifecycle

1. **Draft** — Proposed, no implementation
2. **Experimental** — At least one proof-of-concept
3. **Beta** — Reference implementation + conformance tests
4. **Stable** — Multiple implementations, interoperable
5. **Deprecated** — Superseded
6. **Historic** — No longer in use
